# Evidence selection

This folder contains the screenshots selected for the public project. Each image proves one of four things: the logging pipeline worked, controlled activity occurred, Splunk detected it, or a scheduled alert fired.

## Included

| Files | Reason |
|---|---|
| 01-05 | Platform, audit, Sysmon, forwarder, and data-ingestion validation |
| 06-07 | Controlled persistence and failed-logon activity |
| 08-10 | Splunk investigation results |
| 11 | Final dashboard |
| 12-15 | Successful alert validation |

## Excluded from the public repository

The working session also contained screenshots of VirtualBox display problems, download/install progress, empty searches, malformed commands, connection timeouts, intermediate dashboard menus, provisional alert settings, and other troubleshooting steps. They were useful while building the lab but do not strengthen the final evidence trail. A screenshot that exposed the lab password was also excluded. These files remain part of the private working record and were not copied here.

No screenshots were altered to change their technical content. Files were renamed only to make the sequence understandable.
